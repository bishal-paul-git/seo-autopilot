# SEO playbooks

These notes are what an experienced SEO would check before changing a page. They are guidance, not rules of the search engines: where a statement depends on how search engines currently behave, it says so. **Always prefer Google's own documentation (Search Central) over this summary**, and verify with your own data before acting.

The drafting agent reads these before it writes or edits a page, and the audit, insights and priority reports link their advice back to them.

| Playbook | Use it when |
|---|---|
| [Search intent and page types](search-intent-and-page-types.md) | choosing what a page should be and whether it matches the query |
| [Titles, descriptions and click-through](titles-descriptions-and-ctr.md) | a page ranks but does not get clicks |
| [Technical SEO checklist](technical-seo-checklist.md) | auditing crawling, indexing, canonicals and speed |
| [Cannibalisation and consolidation](cannibalization-and-consolidation.md) | two pages compete for one query |
| [Topical authority and internal linking](topical-authority-and-internal-linking.md) | planning a cluster or fixing weak internal links |
| [Content quality, E-E-A-T and spam policies](content-quality-and-eeat.md) | writing or reviewing any page; staying clear of penalties |
| [Structured data](structured-data.md) | adding or fixing schema markup |
| [Refreshing, merging and pruning](refreshing-and-pruning-content.md) | a page lost visibility, or you have thin or overlapping pages |
| [Redirects, canonicals and migrations](redirects-canonicals-migrations.md) | changing URLs, moving content, retiring pages |
| [AI search visibility](ai-search-visibility.md) | being understood and cited by AI answers |
| [Measuring and experiments](measuring-and-experiments.md) | judging whether a change worked |
