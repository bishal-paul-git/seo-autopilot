# Using the seo-autopilot name

The code is MIT licensed: use it, change it, sell services with it. The name is different. It tells people where something comes from, so this page asks you to use it fairly. This is a project policy, not a claim of a registered trademark.

**Fine without asking**
- Saying your work uses, runs on or is compatible with seo-autopilot ("built on seo-autopilot", "an seo-autopilot setup service").
- Writing about it, teaching it and linking to it.
- Keeping the name in an unchanged copy or a fork that you clearly mark as a fork.

**Please ask first**
- Naming a product, hosted service, company or domain "seo-autopilot", or something easily confused with it.
- Implying that the maintainers endorse, certify or support your product or service.

**Never**
- Using the name for a modified version in a way that makes people think it is the official one.

Questions: open an issue.
