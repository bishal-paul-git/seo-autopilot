How it works

Evidence in, human decision, careful release.

Every step that changes your site waits for you. The rest runs on its own, every day, on GitHub's servers.

Measure

Daily Search Console report and an index check of your pages.

Find

Keyword gaps from your real queries, plus news from the feeds you trust.

Approve

A "Topic" issue arrives with the evidence. Add the label approved, or close it.

Draft

Claude writes the page on a branch and opens a pull request. Your build checks it.

Merge

You read it and merge. Only then is the page queued.

Release

Queued pages get dates, three a day, and the site rebuilds the day each is due.

What you get

A small team's routine work, done every day.

Each job is separate. Turn on what you want.

Daily report

Clicks, impressions, position, and which pages Google has indexed. Near-miss queries and pages with views but no clicks.

Keyword research

Weekly, from your own search data: near-miss, question, rising and uncovered queries. No fake volume numbers.

News and trends

Reads RSS and Atom feeds you choose (regulators, platforms, your industry) and proposes at most one topic a day.

Weekly digest

What changed, what it probably means, what to do next. Includes Google Analytics sessions when connected.

Drafts you approve

Pages arrive as pull requests with sources cited. The agent can only edit your content folders and cannot run code.

Drip scheduling

Approved pages are dated a few a day and released on schedule, so the site grows steadily.

Request-indexing list

Google cannot be automated, so you get the ten pages that need it, each with a direct Search Console link.

Careful backlinks

At most five free-listing attempts a day, one retry, everything logged. Stops at any bot check. Also finds unlinked brand mentions.

Dashboard and local app

One HTML file per site, plus an app on your computer that manages every project in one place.

The rules it keeps

Built to be trusted with your site.

The tools that mass-produce pages put your rankings at risk. This one is designed the other way round.

  • Nothing is published without two human steps: an issue label, then a merged pull request.
  • No invented data. Prompts forbid made-up numbers, prices, clients and quotes. Sources must be real and linked.
  • Read-only Google access. A service account you control, kept in GitHub secrets.
  • Backlinks stay honest. It never solves CAPTCHAs, creates accounts, pays, or swaps links.
  • Your data stays yours. Everything is saved in your own repository. Nothing is sent to us.
Honest limits

What it cannot do.

So you do not find out the hard way.

  • It cannot press Google's Request indexing button. It prepares the list; you press it (about ten a day).
  • There is no keyword-volume data. Research uses your own impressions, and AI ideas are flagged as unverified.
  • Most free backlink directories need an account or show a CAPTCHA. Those are for a person, so it makes the checklist.
  • Nothing guarantees rankings or indexing. It makes the routine work consistent and keeps weak content out.
Install

Three commands in your website's repository.

Needs Node 20 and a GitHub repository. No account with us, no card, no signup.

# 1. scaffold config, data files and GitHub workflows
npx github:bishal-paul-git/seo-autopilot#v2 init --url https://your-site.com/

# 2. connect Google, then check the setup
npx github:bishal-paul-git/seo-autopilot#v2 doctor

# 3. commit, push, and run Actions > seo-daily

Questions

The honest answers.

Will it write pages on its own?

No. It opens an issue with the evidence. A page is only drafted after you add the label approved, arrives as a pull request, and goes live only after you merge it and its scheduled day arrives.

Does it work with WordPress or a CMS?

Reports, research, news, the digest, the indexing list and the dashboard work with any site that has a sitemap. Drafting and scheduling need pages stored as JSON or Markdown files in a repository. A CMS adapter would be a welcome contribution.

What does it cost?

The software is free. GitHub Actions has a free tier that covers the daily jobs for a small site. AI keys and a cloud browser are optional and billed by their providers.

Is my data sent to you?

No. Search data goes from Google to your own GitHub runner and is saved in your own repository. Optional AI calls send short snippets to the provider you choose.

Is it safe to let an agent near my site?

The drafting agent can only edit the content folders you list, cannot run build or test commands, treats issue text as data, and cannot push to your main branch. Your build runs separately with no secrets. See the security notes.
